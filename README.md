# Personal Google Drive File Copier

A personal setup for copying and managing files between Google Drive locations using [rclone](https://rclone.org/).

## Purpose

This project is for personal use only. It allows rclone to authenticate with Google Drive using OAuth 2.0 and perform file operations such as copying and synchronizing files.

## Usage

The Google Drive OAuth authorization is used by rclone to access the associated Google Drive account.

Typical operations may include:

* Copying files between Google Drive locations
* Synchronizing directories
* Managing personal Drive files
* Transferring files between Drive remotes

## Privacy

This is a personal project and is not a public service.

Google Drive data accessed through this setup is not:

* Sold
* Shared with third parties
* Used for advertising
* Used for profiling

OAuth credentials and tokens are used solely to authenticate and authorize access to the associated Google Drive account.

For more information, see the [Privacy Policy](privacy.html).

## Technologies

* [rclone](https://rclone.org/) — file synchronization and management
* Google Drive API — cloud storage access
* Google OAuth 2.0 — authentication and authorization
* GitHub Pages — hosting for the project information and privacy policy
