Personal Google Drive File Copier

This is a personal tool used to copy and manage files between Google Drive locations using rclone.

Personal use only.

This application is not a commercial service and is intended solely for use with my own Google Drive account.

What this application does

The application uses Google's OAuth 2.0 authorization to access Google Drive and allows rclone to perform file operations such as copying and synchronizing files.

Privacy

This application is for personal use. Google Drive data accessed through this application is not sold, shared with third parties, or used for advertising.

OAuth credentials and access tokens are used only to authenticate access to the associated Google Drive account.

For more information, see the Privacy Policy.
